الرئيسية الدروس الأدوات

🛠️ أدوات الأمن السيبراني الأساسية

تعرف على أشهر الأدوات المستخدمة في الفحص والحماية القانونية.

1. أداة Nmap

تُستخدم لفحص الشبكات واكتشاف الأجهزة المتصلة والمنافذ المفتوحة (Ports).

أمر التثبيت في Termux: pkg install nmap

2. أداة Whois

تُستخدم لجمع المعلومات العامة حول أسماء النطاقات (Domains) وتاريخ تسجيلها.

أمر التثبيت في Termux: pkg install whois
